# Icons: abilities and items

Added 2026-11-21. Icons for every Fire, Earth, Water and Air ability and every item in the item database, ready to copy into the game. They were cut from four bought sprite sheets (in `sheets/`), not generated by the art bot, so the art bot's README doesn't list them.

## What's here

| Path | What it is |
|---|---|
| `abilities/<ID>.png` | 85 ability icons, one per bending ability, named by ability ID (`F07.png` = Fireball). Covers F01–F21, E01–E20, W01–W23, A01–A21. |
| `ability_icon_map.csv` | Ability ID, name, branch, mastery, which sheet icon it came from, file path. |
| `items/<item_id>.png` | 172 item icons, named by item ID (`rusty_shortsword.png`). |
| `item_icon_map.csv` | Item ID, name, kind, slot, rarity, tree, retired, which sheet icon it came from, file path. An empty File means no icon yet. |
| `previews/` | Contact sheets of every assignment with names and rarity, for review. Not game assets. |
| `sheets/` | The four original sprite sheets: spells & skills, gear, weapons, items. |
| `sliced/` | Every icon cut from the sheets, sorted by sheet section (`sliced/weapons/sword/sword_20.png`). Use these to swap an icon. The "Icon source" column in the CSVs points here. |

## Sizes and import

- Ability icons are **33x33**: a 32 px tile plus a 1 px drop shadow on the right and bottom.
- Item icons are **36x36**, with transparent space around the art so glow effects fit.
- Pixel art: import with nearest-neighbour filtering, no mipmaps, lossless compression, and no fix-alpha-border. Draw them only at whole-number scales (1x, 2x, 3x), centred in their slot; never stretch them.

## How the icons were picked

**Abilities.** Each bending ability uses the icon from its own element's row of the spells sheet. A few use another row where the element's row had nothing that fit:
- **From the Ice row:** Frost Shard, Ice Spikes and Full Moon.
- **From the Blood row:** Bloodbending.
- **From the Lightning row:** Lightning Bolt, Lightning Redirection and Storm Front.
- **From the Fire row:** Lavabending.
- **New icon:** Blue Fire (F20) is a Fire flame icon recoloured blue.

**Items.**
- **Weapons:** the sword, bow and two-handed hammer icons follow rarity, with plain art for Common and glowing art for Epic.
- **Scrolls:** each of the 85 scrolls is the sheet's parchment scroll with the icon of the ability it teaches set into it. Items named "Codex" use an element-coloured tome instead: red Fire, blue Water, brown Earth, purple Air. So every scroll matches its ability's icon.
- **New icon:** Iron Wolf Pelt is the Wolf Pelt recoloured steel-grey.
- Every non-scroll item has its own icon; none is used twice.

## Not covered

- **Leg slot:** the gear sheet has no trousers or leggings, so these five items have no icon yet: `acolytes_leggings`, `emberstitch_trousers`, `riverweave_breeches`, `quarrymans_trousers`, `breezecloth_leggings`.
- **Weapon abilities:** Sword, Bow and Hammer abilities have no icons in this set.
- **Unused sheet sections:** fishing poles, shovels, food, the rest of the crafting icons, cloaks, belts, rings and the other weapon types are in `sliced/` for later.
